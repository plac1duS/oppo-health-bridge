## 手机定时同步

- [Android 周期工作](https://developer.android.com/reference/androidx/work/PeriodicWorkRequest)：周期任务受省电、Doze 和执行条件影响，不能等同于每天准确 23:30 执行。
- [Android 闹钟与后台调度](https://developer.android.com/develop/background-work/services/alarms)：支持时间触发任务，但精确闹钟有专门权限及适用条件。触发时间与网络同步完成时间必须区分，应用仍需要持久队列和补跑。

此前讨论过 23:30 定时同步；用户已决定将自动化推迟，不再作为第一版要求。

## 托管服务候选

- [Supabase 定价](https://supabase.com/pricing)：免费数据库 500 MB，1 周不活跃可能暂停；Pro 起价 25 美元/月，不能将免费对象存储容量当成数据库容量。
- [Supabase 地域](https://supabase.com/docs/guides/platform/regions)及[HTTPS 函数入口](https://supabase.com/docs/guides/functions/quickstart)：有新加坡地域和默认函数访问入口，可作为省心配置的首轮候选；不保证中国大陆手机实际连通质量。
- [CloudBase for Supabase](https://cloud.tencent.com/product/tcbs)：提供托管 PostgreSQL、认证、REST API 和函数，是国内部署候选。
- [CloudBase 默认域名限制](https://docs.cloudbase.net/service/alias)：其 HTTP 网关默认域名推荐仅用于开发测试，正式服务需要核实自定义域名及相关要求，不能把“免服务器运维”理解成完全无需部署配置。

此前选择 Supabase 作试用候选、CloudBase 作备选；用户已改为电脑本地数据库，这两个候选均不进入当前实施范围。没有创建任何服务或付费。

## 当前结论

已确认（含 2026-10-24 真机验证，详见设计草案第 10 节）：存在相关源码；可在当前电脑开发；用户选择本地数据库、手动同步和 MCP 数据读取。本机路线已验证可读——小米 14 / Android 16 / 已 Root，欢太健康 6.9.37，主库 `database.db` 为 SQLCipher-4 加密，口令经 Android Keystore 解包，经 App 自身句柄已成功枚举 103 张表并读到真实行数。本轮未走云端路线，未使用账号凭证。

待确认：App 进程外用口令离线打开既有库报 `SQLITE_CANTOPEN(14)`（口令已确认正确，疑为定制 `libsqlcipher.so` 默认参数差异）；各指标字段单位、时间戳格式与时区、修订与去重规则、历史最早日期、运动轨迹与心电波形完整性；云端路线的认证方式、登录有效期与 Windows 网络兼容性（尚未尝试）。

未承诺：手表实时数据流、全部历史必定可读、所有品牌互通、手机离线时数据仍实时更新、永久无需重新连接。
